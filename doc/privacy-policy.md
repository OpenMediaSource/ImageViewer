# 隐私策略

**最后更新日期：2026 年 11 月 13 日**

---

## 概述

ImageViewer（以下简称“本软件”）是一款在本机运行的图像查看与处理工具，包括图形界面程序 ImageViewApp 和命令行工具。本隐私策略说明本软件如何处理与您有关的数据。

核心原则：**本软件不收集、不上传您的个人信息、图像内容或使用数据。**

---

## 一、我们不收集的信息

本软件**不会**收集以下信息：

- **个人信息**：不收集姓名、电子邮件地址、电话号码、地理位置等任何可识别个人身份的信息。
- **图像内容**：您打开、查看、编辑或转换的图像文件仅在本机处理，**不会**上传到任何服务器。
- **使用数据**：不收集使用统计、操作记录、崩溃报告或行为分析数据。
- **设备信息**：不收集设备型号、操作系统版本、硬件配置等用于分析或识别个人的信息。设备绑定所需的 Machine ID 仅在本机生成，见第四节。

本软件**不会**：

- 在后台连接互联网或向远程服务器发送数据。
- 包含广告、第三方分析 SDK 或遥测组件。
- 自动上传崩溃报告、日志或诊断信息。

---

## 二、本地处理与网络

- 所有图像读取、显示、转换、缩放、去噪和增强操作都在您的本机完成。
- 本软件不会主动发起网络连接。
- 如果您打开位于网络共享、云同步目录或可移动设备中的文件，文件访问由操作系统完成，本软件不会将文件上传到其他位置。
- `Help > About ImageViewer` 中可能包含第三方网站链接。只有您主动点击时，系统浏览器才会打开对应网页；网页内容由该网站负责，适用其自身的隐私政策。

---

## 三、本机保存的数据

为了记住您的使用偏好，本软件会在程序目录或当前工作目录中保存少量本地数据：

| 数据 | 保存位置 | 用途 | 如何清除 |
|------|----------|------|----------|
| 界面主题、最近打开的文件路径（最多 10 个） | `appConfig.txt` | 恢复主题、方便再次打开最近文件 | 使用 `File > Recent Files > Clear Recent Files` 清空最近列表；删除该文件可同时清除主题 |
| 窗口布局、大小和位置 | `imgui.ini` | 下次启动时恢复界面布局 | 关闭程序后删除该文件 |
| 专业版许可证 | `license.lic` | 记录授权对象、有效期和设备绑定信息 | 删除后程序回到基础版 |
| YUV/RGB 转换配置 | `imageConfig.txt`（可选） | 保存原始像素转换的色彩矩阵设置 | 删除该文件即恢复默认 |
| 处理结果 | 您选择的输出目录 | 保存转换、缩放、增强后的图像 | 由您自行管理 |

以上数据均保存在您的本机，**不会**被发送、同步或上传到任何外部服务。

上述配置文件均为普通文本文件，您可以自行查看或删除。

请特别注意：

- `appConfig.txt` 中的最近文件列表会记录文件路径，可能包含文件夹名称。如果您与他人共用电脑，可以在退出前清空最近文件列表。
- `license.lic` 中可能包含授权对象名称。请勿将许可证文件公开发布或分享给无关人员。

---

## 四、Machine ID 与离线激活

专业版激活可以选择使用 **Machine ID** 进行设备绑定：

- Machine ID 由操作系统提供的设备标识经过单向摘要生成，仅用于区分设备。
- Machine ID 不会包含您的姓名、文件、图像或其他个人内容，也无法通过它还原原始设备标识。
- Machine ID 只在激活窗口中显示，**不会**自动发送给任何服务器。
- 只有在您主动复制 Machine ID 并提供给供应方时，该编号才会离开您的设备。

激活码在本地校验，无需联网。许可证文件只保存在本机。

---

## 五、第三方开源组件

本软件包含若干开源组件，用于图形界面、图像编解码、数学计算和图像增强。这些组件均在本机运行，不包含数据收集、广告或分析功能。主要组件包括：

- Dear ImGui（图形界面）
- GLAD2 / GLFW（OpenGL 支持）
- stb（图像编解码）
- libwebp（WebP 编解码）
- libheif / aom（HEIF/AVIF 编解码，视版本包含）
- LibRaw（Camera RAW 解码，视版本包含）
- Eigen（线性代数）
- giflib、TinyTIFF（GIF/TIFF 支持）
- Anime4K 着色器（图像增强）

---

## 六、数据安全

由于所有数据都在本机处理，且本软件不进行网络传输，您的图像文件和个人数据的安全性主要取决于您设备本身的安全措施。建议您：

- 保持操作系统和安全软件更新。
- 从官方或可信渠道获取本软件。
- 不要随意运行来源不明的修改版程序。
- 妥善保管包含授权信息的 `license.lic` 文件。

---

## 七、儿童隐私

本软件不会收集任何人的个人信息，包括 13 岁以下的儿童。
