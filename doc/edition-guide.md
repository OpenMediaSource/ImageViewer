# 基础版 / 专业版与离线授权说明

ImageViewer 提供**基础版（Basic）**和**专业版（Pro）**两个版本。两者使用同一个程序包，通过离线激活码在运行时切换，无需联网，也无需重新下载。

- **基础版**：无需激活，打开即可使用。支持图像查看、对比、单图格式转换、单图缩放和单图去噪，全部使用 CPU。
- **专业版**：在基础版功能之上，解锁 GPU 加速、批量处理、图像加速（Upscale to 4K、Restore、SDR to HDR、HDR to SDR）和命令行 GPU 加速。

> 基础版中专业功能在菜单里可见但处于置灰状态，并显示「Upgrade to Pro...」入口。

---

## 1. 功能对照

| 功能 | 基础版 | 专业版 |
|------|:------:|:------:|
| 图像查看器 / 对比模式 | ✅ | ✅ |
| 单图格式转换 | ✅（CPU） | ✅（CPU + GPU） |
| 单图缩放 | ✅（CPU） | ✅（CPU + GPU） |
| 单图去噪 | ✅（CPU） | ✅（CPU + GPU） |
| 批量格式转换 | ❌ | ✅ |
| 批量缩放 | ❌ | ✅ |
| 图像加速：Upscale to 4K（Anime4K） | ❌ | ✅ |
| 图像加速：Restore | ❌ | ✅ |
| 图像加速：SDR to HDR | ❌ | ✅ |
| 图像加速：HDR to SDR | ❌ | ✅ |
| GPU 加速（单图转换、去噪、缩放） | ❌（强制 CPU） | ✅ |
| 命令行 `--hw` | ❌（回退 CPU 并提示） | ✅ |

说明：

- 基础版并非只能查看，单图格式转换、缩放和去噪仍然可以使用，只是全部由 CPU 完成。
- 专业版的 GPU 加速会自动选择，不需要额外设置。如果显卡或驱动不满足要求，部分功能会回退 CPU；Restore、SDR to HDR 和 HDR to SDR 没有 CPU 回退。
- 基础版在命令行中传入 `--hw` 不会报错退出，而是提示后使用 CPU。

## 2. 查看当前版本

打开 `Help > About ImageViewer`，可以看到：

- `ImageViewer Edition: Basic` 或 `ImageViewer Edition: Pro`
- 专业版的授权对象（`Licensed to`）和到期时间（`License expires`，如激活码包含）
- 基础版在许可证无效时显示的错误提示

也可以打开 `Help > License / Activate Pro`，窗口顶部会显示当前版本，专业版还会显示授权对象和到期时间。

---

## 3. 激活专业版

激活过程完全离线，不会向任何服务器发送信息。

### 3.1 获取激活码

1. 打开 `Help > License / Activate Pro`。
2. 在窗口底部找到 `Machine ID`。
3. 如果供应方要求设备绑定，点击 `Copy Machine ID` 复制该编号，并连同购买信息一起提供给供应方。
4. 供应方会返回一段激活码（通常以 `IV1.` 开头）。

> 如果激活码不绑定设备，可以跳过复制 Machine ID 的步骤，同一个激活码可以在不同设备上使用。

### 3.2 输入激活码

1. 将激活码完整粘贴到窗口中部的大输入框中。
2. 点击 `Activate`。
3. 激活成功后立即生效，无需重启程序。窗口会显示 `Edition: Pro`、授权对象和到期时间（如有）。

激活码保存后，下次启动程序会自动加载，无需再次输入。

### 3.3 激活结果说明

| 情况 | 窗口提示 |
|------|----------|
| 激活成功 | 显示 `Edition: Pro`、授权对象和到期时间 |
| 激活码为空 | `license is empty` |
| 激活码格式不正确 | `malformed license code` 或 `unsupported license format` |
| 激活码被修改或不完整 | `license signature is invalid` |
| 激活码已过期 | `license expired on YYYY-MM-DD` |
| 激活码绑定的是其他设备 | `license is bound to a different machine` |

激活失败不会影响程序使用，程序会继续以基础版运行。

### 3.4 许可证文件

- 激活成功后，许可证会保存在程序目录的 `license.lic` 中。
- 删除 `license.lic` 后，程序会在下次启动时回到基础版。
- 如果程序目录没有写入权限，激活可能无法保存。请将程序放在有写入权限的目录中，或以有写入权限的账户运行。

## 4. 常见问题

### 4.1 激活码可以在几台电脑上使用？

取决于供应方签发的激活码：

- 不绑定设备的激活码可以在多台电脑上使用。
- 绑定设备的激活码只能在 Machine ID 对应的电脑上使用。

如果需要在另一台电脑上使用，可以向供应方申请新的激活码，或确认原激活码是否支持多设备。

### 4.2 更换电脑或重装系统后需要重新激活吗？

需要。设备绑定的激活码与 Machine ID 关联，更换硬件或重装系统后 Machine ID 可能变化，需要重新获取与当前 Machine ID 匹配的激活码。

### 4.3 激活码会过期吗？

如果供应方签发的激活码包含到期时间，则在到期后自动失效，程序回到基础版。永久激活码没有到期时间。

可以在 `Help > About ImageViewer` 或 `Help > License / Activate Pro` 中查看到期时间。

### 4.4 没有网络可以激活吗？

可以。激活码在本地校验，整个过程不需要联网。

### 4.5 激活后 GPU 功能仍然不可用？

请确认：

- 激活窗口显示的是 `Edition: Pro`。
- 显卡驱动正常，且显卡支持 OpenGL 3.3 及以上版本。
- 程序启动时没有出现 GPU 环境创建失败。
- 当前功能是否需要 GPU：Restore、SDR to HDR 和 HDR to SDR 没有 CPU 回退，GPU 环境不可用时无法使用。

可以先重启程序；仍然不可用则尝试更新显卡驱动。

### 4.6 升级程序后需要重新激活吗？

通常不需要。将新版本程序覆盖到原目录并保留 `license.lic` 即可。如果升级时删除了整个目录，则需要重新输入激活码。

## 5. 命令行工具的版本差异

`formattrans`、`scale`、`rotate`、`imgproc` 同样使用基础版/专业版授权：

- 专业版：`--hw` 生效，使用 GPU 加速。
- 基础版：即使传入 `--hw`，也会打印提示并回退 CPU 执行，不会报错退出。
- `imgproc` 没有 `--hw` 参数，始终使用 CPU。

命令行工具与图形界面同目录部署时，会读取同一份许可证文件，因此只需激活一次。
